Privacy Policy - Discord Meme Bot

Last updated: September 18, 2026

Discord Meme Bot is a personal, single-user automation tool. It forwards posts/reels shared to a specific Instagram account via Direct Message (or TikTok/X links pasted in a DM) to a private Discord channel. It is not a public product, is not distributed to other users, and does not collect data from the general public.

What data is collected

  • Instagram-scoped sender ID of the account that sent a message, as provided by Meta's webhook.
  • Instagram username, resolved via the Instagram Graph API for sender IDs that aren't already recognized.
  • Message content limited to shared post/reel URLs and any TikTok/X links contained in the message text - not general message content unrelated to link sharing.
  • Discord user ID and display name, only for people who voluntarily use the /claim command to associate their Discord identity with an Instagram username.

How this data is used

This data is used solely to decide whether a shared link should be forwarded to the operator's private Discord channel, and to attribute a forwarded link to a Discord user when a matching claim exists. It is not used for advertising, profiling, or analytics, and is not sold or shared with any third party.

Where this data is stored

All data is stored locally, as plain JSON files, on infrastructure controlled by the developer. It is not stored in any third-party database or analytics service. It persists until manually removed by the developer.

Third parties involved

This tool communicates only with the Meta/Instagram Graph API (to receive webhook events and resolve usernames) and the Discord API (to post messages and handle slash commands). No other third party has access to this data.

Data deletion

Anyone whose Instagram sender ID, username, or Discord claim is stored by this tool may request its removal by contacting the developer at the email address below.

Children's privacy

This tool is not directed at, and does not knowingly collect data from, children.

Changes to this policy

This page may be updated occasionally to reflect changes in how the tool operates. The "Last updated" date above will reflect the most recent revision.
